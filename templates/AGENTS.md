# Private coaching workspace

Use the installed codex-coach skill for lessons, diagnostic sessions, reviews, and
saved learning progress. Read COACH_PROFILE.md, LEARNING_PLAN.md,
CHANGE_PROPOSALS.md, the current project brief, and any pending sessions before
continuing. The learner chooses requirements/design/checks; the agent writes code.

Autonomously plan a new small project each week from declared interests and real
skill evidence. Follow the skill's weekly planning workflow; choose difficulty and
five manageable weekday steps without asking for routine project-selection approval.
Use provisional choices when evidence is missing, keep one active project, and
explain any continuation. Daily lessons follow the selected weekly plan. Keep
curriculum decisions separate from changes to active instructions.

Use the profile's language and ask one teaching question at a time. Record only
actual answers. Keep personal understanding separate from artifact completion.
Preparation leaves answer/score fields unassessed and participation/completion false.
Reuse unfinished lessons, preserve answers/rubrics, and reopen files after saving.

Keep instruction proposals separate; only the learner's approval of the exact
change authorizes application. Continue independent teaching while proposals wait.
Coaching preparation does not authorize changes in other projects or their data.
Keep all real profiles, sessions, inventories, evidence, and automation IDs private.
