# Rubrics v1.1 — choose before the learner answers

Each row totals 100. Specialize the criterion to the exercise and retain its
version in the session. Explain sub-scores with evidence from the answer.

| Type | Criteria and weights |
|---|---|
| Design / delegation | Clear outcome 20; requirements and boundaries 30; testable completion criteria 30; workable organization 20 |
| Failure diagnosis | Evidence vs hypotheses 25; supported likely cause 25; discriminating test 30; targeted next action 20 |
| Result evaluation | Requirements coverage 30; real evidence 25; omissions / critical cases 20; reasoned conclusion and certainty limits 25 |
| New concept | Plain accurate explanation 25; new-example application 35; limits / failure cases 20; justified choice 20 |
| Learning project | Requirements / boundaries 20; personal design decisions and concept application 25; test plan / evidence evaluation 35; decision explanation 20 |

Missing answer = not evaluated (`null`), never zero. Track help separately.
Project grading concerns the learner's role, not the code written by the agent.
